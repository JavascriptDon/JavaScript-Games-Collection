## JS Games Collection

A curated collection of small, fast, and fun browser games built with HTML, CSS, and JavaScript.

These projects are perfect for practicing DOM manipulation, game logic, event handling, and state management — the core skills behind interactive front‑end development.


This collection includes:

- 🧠 Memory Game

- 🐍 Snake

- 🐹 Whack‑a‑Mole

- ⌨️ Typing Speed Test
