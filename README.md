## Snake-Game

A fully‑browser‑based retro Snake Game built with HTML, CSS, and JavaScript.

## Features

- 🕹️ Retro Start Menu (inside the canvas)
- ⏸️ Pause / Resume without losing progress
- 🔄 Reset back to the main menu
- 🍎 Food collection & scoring system
- 💥 Game‑over screen (no page reloads)
- 🎧 8‑bit sound effects (Base64 embedded)
- ⚡ Tick‑based movement for classic Snake speed
- 🧭 On‑screen control instructions (top‑right overlay)
- 🎨 Retro pixel font + neon glow header

## Controls 

*Key Action*

- ↑ ↓ ← →	Move the snake
- Enter	Start game / Restart after game over
- P	Pause / Unpause
- R	Reset to main menu

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm (comes with Node.js)

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

After running the command, open the local URL shown in the terminal (usually `http://localhost:5173`) to view the app.

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
## Notes

This project is meant for learning and prototyping. It uses Vite for fast local development and bundling.
